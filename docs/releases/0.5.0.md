SECL 0.5.0 公开测试版 / Public beta

- 新增实例备份与恢复、截图查看和导出、启动记录与日志诊断。Added instance backups and restores, screenshot viewing and export, launch history, and log diagnostics.
- 下载支持暂停、重试和续传。模组、整合包和资源浏览支持 CurseForge 与 Modrinth。Downloads support pause, retry, and resume. Mods, modpacks, and resources can be browsed through CurseForge and Modrinth.

Windows x64：解压整个 ZIP，打开 `SECL/secl.exe`。如果系统缺少 MSVC 运行库，请安装 [Microsoft Visual C++ x64 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。

macOS Apple Silicon：解压后将 `SECL.app` 移到 Applications。此测试包使用临时签名，尚未经 Apple 公证。

On Windows x64, extract the whole ZIP and open `SECL/secl.exe`. Install the Microsoft Visual C++ x64 runtime linked above if Windows reports a missing runtime. On Apple Silicon, extract and move `SECL.app` to Applications. This beta uses ad hoc signing and has not been notarized by Apple.

macOS 的原版和 Fabric + Iris / Sodium 游戏启动已有实机验证。Windows 已验证 Release 打包、原生库加载与自动化测试，完整游戏启动仍待测试。

Vanilla and Fabric + Iris / Sodium game startup have been tested on macOS. Windows Release packaging, native-library loading, and automated checks have been verified. Full game startup on Windows remains to be tested.
